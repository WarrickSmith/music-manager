# Music Manager Documentation

This directory contains documentation and setup files for the Music Manager application.

## Contents

- `music-manager-data-model.md`: Data model definitions for the application
- `appwrite-ss-auth.md`: Next.js server-side authentication code examples
- `AppwriteAPI/`: Appwrite server API reference (database, storage, users)
- `mm-plan.md`, `mm-plan-p5.md`, `mm-plan-p5-brief.md`: Historical planning notes
- `portainer-error.jpg`: Reference screenshot

The Appwrite setup script lives at `scripts/setup-appwrite.ts` and is run via the `setup:appwrite*` npm scripts. Default grade definitions live at `src/lib/appwrite/default-grades.ts`.
